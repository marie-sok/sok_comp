# Загрузка данных компаний


Этот проект загружает данные из JSON-файлов (page_001.json … page_020.json) в SQLite базу данных и выполняет три аналитических запроса.


## Как запустить


1. Убедись, что все файлы `page_*.json` лежат в одной папке со скриптом.
2. Установи Python 3 (если ещё нет).
3. Запусти скрипт из командной строки:
   ```bash
   python load_data.py
