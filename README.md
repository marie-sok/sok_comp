# Загрузка и анализ данных компаний

Небольшой Python-проект: читает `page_*.json`, загружает компании в SQLite и выполняет три аналитических запроса.

## Что делает

- загружает JSON-файлы с компаниями;
- нормализует рейтинг;
- сохраняет записи в `companies.db`;
- показывает топ категорий, средний рейтинг по городам и долю компаний с сайтом;
- содержит отдельный `schema.sql` с базовой схемой и индексами.

## Запуск

Нужен Python 3. Дополнительные пакеты не требуются.

```bash
cd load_data.py
python3 main.py
```

Файлы `page_*.json` должны находиться рядом с `main.py`. SQLite-база `companies.db` создаётся локально и не должна коммититься в Git.

## Структура

```text
load_data.py/
  main.py
  page_*.json
queries.sql
schema.sql
```

> Название каталога `load_data.py/` сохранено ради совместимости с текущей историей проекта; при следующем структурном рефакторинге его логично переименовать в `data_loader/`.
